Guía y Ejemplos de Uso

Cómo funciona la búsqueda: Buscar Personas

Podés buscar por apellido y/o nombre.
  • Si ingresas José encontrarás a las personas con este apellido o nombre.
  • Si ingresas José Ignacio Salinas encontrarás a las personas cuyo apellido y/o nombre contengan alguna de las palabras ingresadas.

Podés buscar por número de legajo ingresando cifras de hasta 6 dígitos, o podés usar "n:" para encontrar legajos de cualquier largo; además la "L:" (sea mayúscula o minúscula) interpretará cualquier número que le siga como un Legajo.

  • Si ingresas 000001 o n:000001, encontrarás a la persona con este legajo.
  • Si ingresas 000001 000012 o n:000001 n:000012, encontrarás a las personas cuyos legajos se encuentren dentro del rango ingresado.
  • Si ingresas 000001 000006 000012 o n:000001 n:000006 n:000012, encontrarás a las personas con cada uno de estos legajos.
  • Si ingresas l:000001 000006 000012, encontrarás a las personas con cada uno de estos legajos.

Podés buscar por correo electrónico ingresando el dominio completo (persona@organizacion.com).

Podés buscar por el Identificador Fiscal ingresando una cifra a partir de 7 dígitos.
* Nota:

¡Todos los casos de Búsqueda anteriormente mencionados son combinables!
