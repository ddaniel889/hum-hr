Guía y Ejemplos de Uso

Cómo funciona la búsqueda: Buscar Documentación

Podés buscar por período ingresando 01/2020 ó 2020/01.
  • Si ingresas 01/2020 encontrarás los documentos del período indicado.
  • Si ingresas 01/2020 12/2020 encontrarás los documentos que se encuentren dentro del rango de períodos indicados.
  • Si ingresas 01/2020 06/2020 12/2020 encontrarás los documentos de cada uno de los períodos indicados.

Podés buscar por el nombre del tipo de documentación.

Podés buscar por apellido y/o nombre de una persona.
  • Si ingresas José encontrarás los documentos de las personas con este apellido o nombre.
  • Si ingresas José Ignacio Salinas encontrarás los documentos de las personas cuyos apellidos y/o nombres contengan alguna de las palabras ingresadas.

Podés buscar por número de legajo ingresando cifras de hasta 6 dígitos, o podés usar "n:" para encontrar legajos de cualquier largo; además la "L:" (sea mayúscula o minúscula) interpretará cualquier número que le siga como un Legajo.

  • Si ingresas 000001 o n:000001, encontrarás los documentos de la persona con este legajo.
  • Si ingresas 000001 000012 o n:000001 n:000012, encontrarás los documentos de las personas cuyos legajos se encuentren dentro del rango ingresado.
  • Si ingresas 000001 000006 000012 o n:000001 n:000006 n:000012, encontrarás los documentos de las personas con cada uno de estos legajos.
  • Si ingresas l:000001 000006 000012, encontrarás los documentos de las personas con cada uno de estos legajos.

Podés buscar por el Identificador Fiscal de la persona ingresando una cifra de hasta 7 dígitos.

* Nota:

¡Todos los casos de Búsqueda anteriormente mencionados son combinables!

Podés buscar por el Identificador del documento

  • Si ingresas docid:, en mayúscula o minúscula, interpretará que el número que siga es un Identificador de documento.
  • Si ingresas docid:000001, encontrarás el documento cuyo identificador coincida con el número ingresado.
